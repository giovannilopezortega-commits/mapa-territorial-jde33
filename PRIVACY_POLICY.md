# Política de privacidad — Mapa Territorial JDE 33

Última actualización: 24 de septiembre de 2026.

La aplicación puede solicitar ubicación únicamente al usar “Mi ubicación”. La coordenada se procesa en el dispositivo para identificar sección y manzana y no se almacena en una base de datos propia.

La aplicación consume recursos cartográficos de terceros (OpenStreetMap, Esri y Leaflet). Si el usuario elige “Cómo llegar”, se abre Google Maps con el destino seleccionado. Estos servicios pueden procesar datos técnicos conforme a sus propias políticas.

La aplicación no solicita nombre, correo, teléfono, contraseña ni crea perfiles personales. La versión web puede usar caché local para mejorar rendimiento y disponibilidad.

Versión web de esta política: `privacy.html`.

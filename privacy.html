Política de privacidad

Mapa Territorial JDE 33 es una herramienta cartográfica para consultar secciones, manzanas y facilitar la navegación de campo.

Ubicación

La aplicación puede solicitar acceso a la ubicación del dispositivo únicamente cuando la persona usuaria utiliza la función “Mi ubicación”. La coordenada se procesa en el dispositivo para identificar la sección y manzana correspondiente. La aplicación no mantiene una base de datos propia de ubicaciones de las personas usuarias.

Servicios externos

La aplicación utiliza mapas y recursos servidos por terceros, entre ellos OpenStreetMap, Esri y Leaflet. Al utilizar estos recursos, dichos proveedores pueden recibir información técnica habitual de una conexión a Internet, como dirección IP y datos del navegador o dispositivo, conforme a sus propias políticas.

Si la persona usuaria selecciona “Cómo llegar”, la aplicación abre Google Maps con las coordenadas del destino seleccionado. El uso posterior de Google Maps se rige por las condiciones y políticas de Google.

Almacenamiento local

La versión web puede almacenar temporalmente archivos de la aplicación en la memoria caché del navegador para mejorar la disponibilidad y el rendimiento. Este almacenamiento no contiene una cuenta personal ni un historial de ubicación generado por esta aplicación.

Datos personales

La aplicación no solicita nombre, correo electrónico, teléfono, contraseña ni crea perfiles de usuario.

Contacto y cambios

Esta política podrá actualizarse cuando cambien las funciones de la aplicación o los requisitos de publicación. La versión vigente estará disponible en esta misma dirección.

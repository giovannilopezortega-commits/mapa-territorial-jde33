# Android — Mapa Territorial JDE 33

Proyecto Android contenedor para la aplicación web publicada en GitHub Pages.

## Requisitos
- Android Studio compatible con Android Gradle Plugin 9.4
- JDK 17
- Android SDK 36
- Gradle 9.6

## Identificador
`com.giovannilopez.mapaterritorialjde33`

No cambies este identificador después de publicar la primera versión en Google Play.

## Generar el App Bundle
1. Abre la carpeta `android` en Android Studio.
2. Espera la sincronización de Gradle.
3. Ve a **Build > Generate Signed App Bundle or APK**.
4. Elige **Android App Bundle**.
5. Crea o selecciona tu keystore de publicación.
6. Elige la variante **release**.
7. Guarda de forma segura el keystore y sus contraseñas.
8. El resultado será un archivo `.aab` para Play Console.
